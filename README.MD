# FishCam - Système de Gestion des Dettes & Épargnes

## Description
Application Spring Boot pour la gestion des dettes clients et des épargnes dans les poissonneries.

## Fonctionnalités
- ✅ Gestion multi-poissonneries
- ✅ Gestion des clients
- ✅ Gestion des dettes avec historique
- ✅ Gestion des épargnes (dépôts/retraits)
- ✅ Fonctionnalité "Payer dette avec épargne"
- ✅ Notifications automatiques (dettes > 5000 FCFA, rappels dimanche)
- ✅ Rapports PDF
- ✅ API REST complète

## Technologies
- Java 17
- Spring Boot 3.5.8
- PostgreSQL
- MapStruct
- iTextPDF
- Swagger
